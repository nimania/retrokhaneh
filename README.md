# رتروخانه

**رتروخانه** یک پرتال فارسی برای خبر و فرهنگ رترو است: بازی و کنسول، فناوری قدیمی، موسیقی و فرمت‌های فیزیکی، سینما و تلویزیون، خودرو کلاسیک، طراحی، مد و سبک، کلکسیون و «ایران رترو».

## نسخهٔ فعلی

نسخهٔ 2026-09-30 از یک لندینگ گرافیکی سنگین به یک رابط رسانه‌ای ساده و داده‌محور تبدیل شده است:

- صفحهٔ اصلی خبری با خبر اصلی، تازه‌ها و موضوعات
- جستجوی سمت کاربر
- فیلتر موضوعی
- حالت روشن/تیره
- طراحی واکنش‌گرا و ناوبری موبایل
- فایل مستقل \`data/news.json\` برای خبرها
- لینک مستقیم هر خبر به منبع اصلی

خبرهای موجود در JSON صرفاً دادهٔ اولیهٔ واقعی برای راه‌اندازی پرتال هستند و هرکدام به منبع اصلی خود لینک می‌شوند.

## مسیر بعدی

معماری عمداً ساده نگه داشته شده تا در مرحلهٔ بعد یک GitHub Action بتواند RSS/Feedهای منتخب را بخواند، خبرها را نرمال‌سازی و دسته‌بندی کند و \`data/news.json\` را به‌روزرسانی کند. در همان مرحله می‌توان بخش «ایران رترو»، صفحات موضوعی، آرشیو روزانه و خبرهای فارسی را نیز اضافه کرد.
