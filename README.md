# رتروخانه

خانهٔ فارسی فرهنگ رترو، با «رتروپدیا» به‌عنوان بخش آرشیو و فضایی برای معرفی داینر نیما.

این نسخه یک صفحهٔ آغازین ایستا و بدون وابستگی ساخت است. برای GitHub Pages، مخزن را با نام `retrokhaneh` بسازید، فایل‌ها را در ریشه قرار دهید و در Settings → Pages، منبع `Deploy from a branch` و شاخهٔ `main`، پوشهٔ `/ (root)` را انتخاب کنید. نشانی سایت سپس `https://nimania.github.io/retrokhaneh/` خواهد بود. لینک‌ها نسبی هستند و در این مسیر کار می‌کنند.

مدخل‌های آرشیوی و اطلاعات داینر تا زمان تهیه و تأیید محتوا به‌صورت جای‌نگهدار باقی می‌مانند؛ ادعای تاریخی یا اطلاعات کسب‌وکار ساختگی منتشر نشده است.
